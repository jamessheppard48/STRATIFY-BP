# Prediction Model Pipeline: Derivation and Validation

This repository contains the analysis scripts required to replicate the prediction model. The analysis splits tasks between R (for model derivation) and Stata (for validation).

## Execution Order & Workflow

1. **`[Shared model derivation codes].R`** (Run First)
   - **Purpose:** derives the primary prediction model.
   - **Inputs:** Requires `[Your datafile].csv` in the data directory.
   - **Outputs:** Generates `[PIcomb].csv` (or .dta) used for validation.

2. **`[Shared calibration and validation codes].do`** (Run Second)
   - **Purpose:** Assess model performance - Runs model calibration curves and validation metrics.
   - **Inputs:** Requires the processed output generated by the R script (`[PIcomb].dta`)
   - **Outputs:** Generates validation tables and calibration plots.

## Software Prerequisites
- R (version 4.5.2)
- Stata (version MP 16.1)
