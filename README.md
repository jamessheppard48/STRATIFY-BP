# STRATIFY-BP
Clinical codelists for variables used in the STRATIFY-BP project

The data used in this analysis are provided by the Clinical Practice Research Datalink (CPRD) via an institutional licence. Requests for data sharing should be made directly to the CPRD via their online system https://www.erap.cprd.com/. CPRD also provide synthetic data which could be used to run this code. Applications for access to synthetic data can be made via https://www.cprd.com/data/synthetic-data.
